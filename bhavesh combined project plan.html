Core modules explained
taylor_rule.py
Quant centrepiece
  • Estimate India's output gap using Hodrick-Prescott filter on GDP data
  • Inflation gap = actual CPI minus RBI target (4%)
  • Taylor Rule: r* = neutral_rate + 0.5 × (inflation_gap) + 0.5 × (output_gap)
  • Calibrate neutral rate using average real repo rate over 2015–2019 pre-COVID period
  • Key finding to test: when Taylor Rule deviation exceeds 75bps, RBI adjusts within 2 quarters — verify historically
nelson_siegel.py
Direct SOFR analog
  • Fit Nelson-Siegel model to G-Sec spot curve: y(t) = β₀ + β₁·(1−e^(−t/τ))/(t/τ) + β₂·((1−e^(−t/τ))/(t/τ) − e^(−t/τ))
  • β₀ = level, β₁ = slope, β₂ = curvature — exactly the decomposition you did mentally at Axxela
  • Extract implied forward rates from fitted parameters
  • Historical β₀/β₁/β₂ behaviour before/after RBI cut cycles = your analytical contribution
  • This is the module quant reviewers will spend the most time on
signal_backtest.py — the most important module
Walk-forward only
  • Signal: go long 10Y G-Sec when Taylor Rule gap > 75bps AND CPI momentum falling
  • Walk-forward validation: train on 2015–2021, test on 2022–2025. Never touch the test set during development.
  • Performance metrics: out-of-sample Sharpe, max drawdown, hit rate, information ratio vs. buy-and-hold
  • Transaction cost adjustment: 5bps round-trip on G-Sec futures
  • Report the out-of-sample Sharpe honestly — even 0.4 with proper methodology is impressive. A suspiciously high number will be challenged immediately in a Graviton interview.

One honest note on the Sharpe ratio
The out-of-sample Sharpe is the single most important number in this project for quant firms. Do not adjust or round it upward. If it's 0.4, report 0.4 — a low but honest out-of-sample Sharpe with rigorous walk-forward methodology is more impressive to Graviton and Quadeye than a suspiciously high backtest number. They will ask exactly how you validated it in the interview. The answer "walk-forward, train 2015–2021, test 2022–2025, never touched test set during development" is what gets you to the next round.
